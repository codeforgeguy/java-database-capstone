# Smart Clinic Management System - User Stories

## Admin User Stories
- **US1.1: Manage Users and Roles**
  - **As an** Admin,
  - **I want to** add, update, and manage doctor and patient accounts,
  - **So that** only authorized individuals have access to the system.
- **US1.2: System and Clinic Overview**
  - **As an** Admin,
  - **I want to** view clinic-wide appointment analytics and system health,
  - **So that** I can ensure smooth daily operations.

## Patient User Stories
- **US2.1: Book an Appointment**
  - **As a** Patient,
  - **I want to** browse available doctors and schedule an appointment slot,
  - **So that** I can receive timely medical consultation.
- **US2.2: View and Manage Appointments**
  - **As a** Patient,
  - **I want to** view, reschedule, or cancel my upcoming appointments,
  - **So that** I can keep my healthcare schedule up to date.
- **US2.3: Access Medical Records & Prescriptions**
  - **As a** Patient,
  - **I want to** access my diagnostic records and digital prescriptions online,
  - **So that** I can review doctor recommendations anytime.

## Doctor User Stories
- **US3.1: Manage Schedule and Availability**
  - **As a** Doctor,
  - **I want to** set and adjust my available consultation hours,
  - **So that** patients can only book appointments when I am on duty.
- **US3.2: Manage Patient Appointments and Records**
  - **As a** Doctor,
  - **I want to** view my daily appointment list and access patient medical histories,
  - **So that** I can provide informed and effective treatments.
- **US3.3: Issue Digital Prescriptions**
  - **As a** Doctor,
  - **I want to** create and attach prescription records to a patient profile,
  - **So that** patients and pharmacies receive clear medication instructions.
